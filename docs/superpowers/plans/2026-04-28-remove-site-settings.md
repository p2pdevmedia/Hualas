# Remove /admin/site Settings and Migrate to Hardcoded Icons

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Remove the dynamic site settings admin page and database table, replacing them with hardcoded favicon and logo URLs.

**Architecture:** This is a straightforward removal task. Currently favicon and logo are stored in a `SiteSetting` database table and retrieved dynamically. We'll replace the IPFS hash references with fixed URLs that point to the current default values already in use as fallbacks. This eliminates the admin overhead and database dependency for branding assets.

**Current State:**
- `/admin/site/` page allows SUPER_ADMIN to upload logo and favicon to Pinata/IPFS
- `src/app/api/site-settings/route.ts` handles GET/POST for the SiteSetting table
- `src/app/layout.tsx` fetches settings for favicon in metadata
- `src/components/navbar.tsx` fetches settings for logo, falls back to `defaultLogo`
- Current `defaultLogo` URL: `https://lh6.googleusercontent.com/hX1qgSPLZYte1_e1xQwiDdMTxlxH3h1isoxUqgXoFnylzCCyiLC8q9dvMSSM-cbtHBdkrl_wlkqyknspAH12YnDAIEIdo5fmegdteoOHIUNEK_nu_0fHbE6J6S5WtghSXZiqIPcd1A=w16383`
- No favicon currently set in database (returns `undefined`)

**Tech Stack:**
- Next.js 14 (App Router)
- Prisma with PostgreSQL
- TypeScript

## Task 3: Update Root Layout

**Files:**

- [ ] **Step 1: Read current layout.tsx**

Already done. The metadata generation fetches `SiteSetting` and builds an IPFS URL. Since no favicon is currently in the database, we'll use a fallback fixed URL.

- [ ] **Step 2: Replace dynamic metadata generation**

Replace:
```typescript
export async function generateMetadata() {
  const settings = await getSiteSettings();
  const iconUrl = settings?.favicon
    ? `https://gateway.pinata.cloud/ipfs/${settings.favicon}`
    : undefined;
  return {
    title: 'Hualas Club',
    description: 'Club de montaña en San Martín de los Andes, Patagonia',
    icons: iconUrl ? [{ url: iconUrl }] : undefined,
  };
}

async function getSiteSettings() {
  try {
    return await prisma.siteSetting.findUnique({ where: { id: 1 } });
  } catch {
    return null;
  }
}
```

With:
```typescript
export async function generateMetadata() {
  return {
    title: 'Hualas Club',
    description: 'Club de montaña en San Martín de los Andes, Patagonia',
    icons: [{ url: '/favicon.ico' }],
  };
}
```

Remove the `getSiteSettings` function entirely and remove the `prisma` import if it's no longer used elsewhere.
